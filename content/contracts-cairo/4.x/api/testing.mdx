<Callout type='info'>
The `openzeppelin_testing` package is versioned independently from the `openzeppelin` umbrella package. Contracts for Cairo `v{{umbrella_version}}` uses `openzeppelin_testing` version `{{openzeppelin_testing_version}}`.
</Callout>

Add the package as a development dependency:

```toml
[dev-dependencies]
openzeppelin_testing = "{{openzeppelin_testing_version}}"
```

See the versioned [API index](https://github.com/OpenZeppelin/cairo-contracts/blob/openzeppelin_testing-v{{openzeppelin_testing_version}}/packages/testing/docs/openzeppelin_testing.md), [API summary](https://github.com/OpenZeppelin/cairo-contracts/blob/openzeppelin_testing-v{{openzeppelin_testing_version}}/packages/testing/docs/SUMMARY.md), or [Scarb registry entry](https://scarbs.xyz/packages/openzeppelin_testing).
