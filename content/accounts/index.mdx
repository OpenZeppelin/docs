## Why ERC-7579?

ERC-7579 (Minimal Modular Smart Accounts) has emerged as the leading standard for modular smart account architecture. OpenZeppelin Accounts focuses exclusively on ERC-7579 because:

- **Wide Adoption**: The modular standard is well-adopted across the ecosystem
- **Module-Based Architecture**: Install functionality as modules rather than through inheritance
- **No Redeployment Required**: Add new features to existing accounts without redeploying
- **Wallet Provider Friendly**: Most wallet providers support module installation without requiring account redeployment

Unlike inheritance-based approaches that require redeploying the entire account contract, ERC-7579's modular design allows you to install, update, and remove functionality dynamically, making it the ideal choice for production smart account implementations.
