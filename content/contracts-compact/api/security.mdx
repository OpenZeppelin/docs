This package provides the API for all Security modules.

<Callout type='info'>
  For an overview of the module, read the [Security guide](../security).
</Callout>

The page covers the following modules:

- [Initializable](#Initializable): a one-time initialization guard.
- [Pausable](#Pausable): an emergency stop mechanism.
- [Allowlist](#Allowlist): a permit-list keyed by account identifier.
- [Blocklist](#Blocklist): a deny-list keyed by account identifier.

## Initializable [toc] [#Initializable]
<APIGithubLinkHeader
    moduleName="Initializable"
    link={`https://github.com/OpenZeppelin/compact-contracts/blob/v0.3.0/contracts/src/security/Initializable.compact`}
/>

```ts
import "./node_modules/@openzeppelin/compact-contracts/security/Initializable";
```

<Callout type='warn'>
  Use this module only at the top contract layer, and import it into at most one module per contract.
  When two modules in the same directory both import Initializable, the compiler collapses their
  `_isInitialized` flags into a single shared ledger slot
  ([compact#270](https://github.com/LFDT-Minokawa/compact/issues/270)): initializing one marks the other
  as initialized. The OpenZeppelin modules do not import this module; each tracks its own `_isInitialized` flag inline.
</Callout>

## Allowlist [toc] [#Allowlist]
<APIGithubLinkHeader
    moduleName="Allowlist"
    link={`https://github.com/OpenZeppelin/compact-contracts/blob/v0.3.0/contracts/src/security/Allowlist.compact`}
/>

```ts
import "./node_modules/@openzeppelin/compact-contracts/security/Allowlist";
```

A minimal permit-list keyed by a `Bytes<32>` account identifier.
The mutators `_allow` and `_disallow` are ungated: the implementing contract must protect them with its own access control
and decides where `assertAllowed` applies.
Membership is public and the approved set is publicly enumerable.
