**OpenZeppelin Contracts for Compact** is a library of modules for secure smart contract development on Midnight.

  <Card href={`/contracts-compact/${latestStable}`} title={`Overview (${latestStable})`}>

## Modules

<Cards>
  <Card href={`/contracts-compact/${latestStable}/ownable`} title="Ownable">
    Restrict circuits to a single owner, with a shielded-owner variant.
  </Card>
  <Card href={`/contracts-compact/${latestStable}/access-control`} title="AccessControl">
    Grant and enforce permissions with role-based access control.
  </Card>
  <Card href={`/contracts-compact/${latestStable}/shielded-access-control`} title="ShieldedAccessControl">
    Role-based access control that hides who holds each role.
  </Card>
  <Card href={`/contracts-compact/${latestStable}/security`} title="Security">
    Initializable, Pausable, Allowlist, and Blocklist modules.
  </Card>
  <Card href={`/contracts-compact/${latestStable}/fungible-token`} title="FungibleToken">
    Fungible tokens, an approximation of EIP-20.
  </Card>
  <Card href={`/contracts-compact/${latestStable}/non-fungible-token`} title="NonFungibleToken">
    Non-fungible tokens, an approximation of EIP-721.
  </Card>
  <Card href={`/contracts-compact/${latestStable}/multi-token`} title="MultiToken">
    Multiple token types in one contract, an approximation of EIP-1155.
  </Card>
  <Card href={`/contracts-compact/${latestStable}/native-shielded-token`} title="NativeShieldedToken">
    Mint and burn Midnight shielded coins of the contract's own color.
  </Card>
  <Card href={`/contracts-compact/${latestStable}/confidential-fungible-token`} title="ConfidentialFungibleToken">
    Fungible tokens with ElGamal-encrypted balances on the public ledger.
  </Card>
  <Card href={`/contracts-compact/${latestStable}/crypto`} title="Crypto">
    ElGamal and EcdhMask encryption over Jubjub, the ECDSA low-s rule, and the EIP-712 envelope.
  </Card>
  <Card href={`/contracts-compact/${latestStable}/multisig`} title="Multisig">
    Signer registry, proposals, treasuries, and threshold-ECDSA presets for contract-held funds.
  </Card>
  <Card href={`/contracts-compact/${latestStable}/utils`} title="Utils">
    Account identifiers, helper circuits, and EVM ABI word encoding.
  </Card>
</Cards>
